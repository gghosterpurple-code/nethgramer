# Как выложить Nethgram в интернет бесплатно

**Схема:** сервер на **Render** (бесплатно, без рекламы и водяных знаков, свой адрес `https://<имя>.onrender.com`) + база данных **Neon PostgreSQL** (бесплатно, данные хранятся постоянно и не пропадают, когда сервер засыпает или перезапускается).

| | Render (сервер) | Neon (база данных) |
|---|---|---|
| Цена | 0 ₽ | 0 ₽ |
| Банковская карта | не нужна | не нужна |
| Водяные знаки / реклама | нет | нет |
| Лимиты | 512 МБ ОЗУ, 750 ч в месяц (хватает на 24/7 одного сервиса) | 1 ГБ данных, 100 CU-часов в месяц |
| Сон | засыпает через 15 мин без посетителей, просыпается ~1 мин | засыпает через 5 мин, данные **сохраняются** |

Для ~50 человек этого достаточно.

> Почему не бесплатная база самого Render: она **удаляется через 30 дней**. База Neon не истекает.

---

## Шаг 1. База данных Neon (5 минут)

1. Зайдите на **https://neon.com** → *Sign up* (можно через GitHub или Google).
2. Создайте проект: *Create project* → имя `nethgram`, Postgres 17, регион **Europe (Frankfurt)** (ближе к пользователям из СНГ).
3. На главной странице проекта нажмите **Connect** и скопируйте строку подключения вида
   `postgresql://neondb_owner:XXXX@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
4. Сохраните её — это ваш `DATABASE_URL`. **Никому её не показывайте.**

Таблицу создавать не нужно — сервер создаст её сам при первом запуске.

## Шаг 2. Загрузить проект на GitHub (5 минут)

Render берёт код из GitHub.

1. Зарегистрируйтесь на **https://github.com** (если ещё нет аккаунта).
2. Создайте репозиторий: *New repository* → имя `nethgram` → **Private** (приватный — так код и настройки не увидят посторонние) → *Create repository*.
3. Загрузите файлы проекта. Проще всего — через **GitHub Desktop** (https://desktop.github.com):
   *File → Add local repository →* папка `C:\Users\plonk\Desktop\pu12-main` → *create a repository* → *Publish repository* (галочка **Keep this code private** включена).

   Или командами в терминале из папки проекта:
   ```bash
   git init
   git add .
   git commit -m "Nethgram"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/nethgram.git
   git push -u origin main
   ```

Лишнее (папка `backups/`, `node_modules`, локальные данные из `data/`) в репозиторий не попадёт — это настроено в `.gitignore`.

## Шаг 3. Сервер на Render (5 минут)

1. Зайдите на **https://render.com** → *Get Started* → войдите **через GitHub**.
2. Нажмите **New + → Blueprint** и выберите репозиторий `nethgram`.
   Render сам прочитает файл `render.yaml` из проекта (бесплатный план, команды сборки и запуска уже прописаны).
3. Render попросит заполнить две переменные:
   - `DATABASE_URL` — строка подключения из Neon (шаг 1);
   - `ADMIN_PASSWORD` — **придумайте новый** пароль администратора для команды `/l` в боте Nethgram.
4. Нажмите **Apply / Deploy**. Через 2–4 минуты сервис запустится.
5. Откройте *Logs* — должно быть:
   ```
   [db] PostgreSQL подключён, база пустая — начинаем с нуля
   ```
   (при следующих запусках: `[db] PostgreSQL: загружено строк — N`).
6. Адрес мессенджера — вверху страницы сервиса: `https://nethgram-xxxx.onrender.com`. Его можно отправлять друзьям.

> Если вместо Blueprint создаёте сервис вручную (*New + → Web Service*): Runtime **Node**, Build Command `npm install --omit=dev`, Start Command `node server/server.js`, Instance type **Free**, Health Check Path `/healthz`, и добавьте те же две переменные в *Environment*.

## Шаг 4 (по желанию). Чтобы сервер не засыпал

Бесплатный Render засыпает через 15 минут без посетителей, и первый вход потом грузится около минуты. Данные при этом **не теряются** — они в Neon. Если хотите, чтобы сайт открывался сразу:

1. Зайдите на **https://cron-job.org** (бесплатно) → зарегистрируйтесь.
2. *Create cronjob* → URL: `https://<ваш-адрес>.onrender.com/healthz` → интервал **каждые 10 минут** → *Create*.

750 бесплатных часов Render в месяц хватает, чтобы один сервис работал круглосуточно (в месяце максимум 744 часа). Не создавайте второй бесплатный сервис в том же аккаунте — часы общие.

## Обновление мессенджера

Внесли изменения → загрузили в GitHub (*Commit* и *Push* в GitHub Desktop) → Render сам пересоберёт и перезапустит сервер. Данные остаются в базе.

## Что важно знать

- **Фото** перед отправкой сжимаются до 1280 px, чтобы не переполнить 1 ГБ базы. Следите за местом в панели Neon (*Storage*). Если подходит к 1 ГБ — удалите старые чаты или перейдите на платный план.
- **Канал Nethgram news (@neth)** создаётся автоматически, на него подписываются все новые пользователи. Право публиковать даёт секретная команда в боте Nethgram (по умолчанию `/imrerowq1`). Если репозиторий публичный, задайте свою команду в Render → Environment: `NEWS_POSTER_COMMAND` = например `/мой_секрет123`.
- **Пароль администратора** теперь берётся из `ADMIN_PASSWORD`. Старый пароль из кода работает только локально, когда переменная не задана.
- **Резервная копия базы:** в панели Neon → *Branches* можно сделать копию (branch) перед большими изменениями.
- Если сервер не стартует и в логах `Не удалось загрузить данные из базы` — проверьте `DATABASE_URL` (лишние пробелы, `?sslmode=require` на конце).
