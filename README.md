# 🚀 Nethgram — Запуск сервера

> Как выложить мессенджер в интернет бесплатно — пошагово в файле **[DEPLOY.md](DEPLOY.md)**.

## Требования
- Node.js 16+ (https://nodejs.org)
- Зависимость одна: `pg` (драйвер PostgreSQL), ставится командой `npm install`. Без базы данных сервер работает по-старому, через файл `data.json`.

## Структура проекта

```
pu12-main/
├── server/            бэкенд (Node.js): HTTP + WebSocket, боты, логика
│   ├── server.js      точка входа: загружает данные и запускает app.js
│   ├── app.js         весь сервер: регистрация, чаты, каналы, боты, подарки, VELO$IPE
│   └── storage.js     хранилище: PostgreSQL (DATABASE_URL) или data/data.json
├── client/            фронтенд
│   └── client.html    всё веб-приложение одним файлом (HTML + CSS + JS)
├── static/            статика, отдаётся по /assets, /gifts, /stickers
│   ├── assets/        иконки, эмодзи, обои
│   ├── gifts/         анимации подарков (Lottie .json)
│   └── stickers/      стикеры
├── data/              локальные данные (data.json) — не попадает в git
├── backups/           старые версии файлов — не попадает в git
├── tools/             вспомогательные скрипты
├── package.json       зависимости и команда запуска
├── render.yaml        настройки хостинга Render
└── DEPLOY.md          как выложить в интернет
```

## Запуск

1. Открой терминал в папке проекта
2. Установи зависимости (один раз): `npm install`
3. Запусти:

```bash
npm start
```

4. Открой в браузере: **http://localhost:3000**

## Как пользоваться

1. Введи номер телефона (код страны +1, +555, +7, +99966)
2. Появится уведомление с кодом — кликни по нему или введи вручную
3. Введи имя и фамилию (необязательно)
4. Готово! Можешь писать в боты или искать других пользователей

## Многопользовательский режим

- Открой **несколько вкладок** браузера и зарегистрируйся под разными именами
- Используй поиск в боковой панели чтобы найти других пользователей
- Переписка работает в реальном времени через WebSocket

## Данные

Локально (без `DATABASE_URL`) данные сохраняются в файл `data/data.json` (если там его нет, сервер один раз подхватит старый `data.json` из корня).
На хостинге данные хранятся в PostgreSQL — см. раздел ниже и **DEPLOY.md**.

## Порт

По умолчанию: **3000**. Чтобы изменить — задай переменную окружения `PORT` (хостинг делает это сам).

## 💾 База данных (чтобы данные не пропадали на Render)

На бесплатном Render диск стирается при каждом засыпании и деплое, поэтому `data.json` там не сохраняется.
Если задана переменная окружения `DATABASE_URL`, данные хранятся в PostgreSQL и переживают сон и перезапуски.

1. Создай бесплатную базу, например на **neon.tech** (или supabase.com), и скопируй строку подключения вида `postgresql://user:pass@host/db?sslmode=require`.
2. В Render: твой сервис → **Environment** → добавь `DATABASE_URL` = эта строка.
3. Build Command: `npm install`, Start Command: `node server/server.js`. Нажми **Manual Deploy**.
4. В логах должно появиться: `[db] PostgreSQL подключён` / `загружено строк — N`.

Как это работает:
- Таблица `nethgram_kv` создаётся сама. Каждый пользователь, чат, канал, подарки и т.д. — отдельная строка (jsonb); при сохранении пишутся только изменившиеся.
- Если база пустая, а локально есть `data/data.json` (или старый `data.json` в корне) с пользователями, данные переносятся в базу автоматически.
- Если база недоступна при старте, сервер **не запускается** (чтобы не затереть данные пустым состоянием).
- При остановке (SIGTERM от Render) сервер дописывает всё в базу перед выходом.
- Локально без `DATABASE_URL` всё работает как раньше.
